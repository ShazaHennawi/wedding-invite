# Isaac & Shaza Wedding Invitation

A responsive, interactive wedding invitation for Isaac and Shaza, built with
React, vinext, and TypeScript.

## Privacy

This project contains private event information and bank-transfer details.
Keep the GitHub repository **private** and do not publish the source through
GitHub Pages.

## Local development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

The local invitation is available at `http://localhost:3000`.

## Validation

```bash
npm run build
npm run lint
```

## Hosting

The production invitation is configured for OpenAI Sites through
`.openai/hosting.json`. GitHub should be used as a private source repository;
production publishing remains managed through Sites.
